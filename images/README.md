# Engineering Design Images

This directory contains selected visual results from the shredding-cum-composting machine project.

The figures included here focus on:

- Machine assembly and mechanical design
- Component and mechanism design
- Engineering drawings
- Blade design concepts
- Structural/FEA results
- Fabricated prototype, where supported by the project documentation

The original academic project report is not included because it contains student identification, signatures, and administrative information.

This was a team university project. Individual task ownership is not assigned unless explicitly supported by the available project documentation.
